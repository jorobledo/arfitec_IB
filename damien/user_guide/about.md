# ARFITEC ToF Analysis Software

**Version:** 1.0

---

## Description

ARFITEC ToF Analysis Software is a graphical application developed for the analysis of neutron Time-of-Flight (ToF) experiments and Neutron Activation Analysis (NAA).

The software provides tools to:

- [Load and visualize multiple experimental datasets](./pages/plot_reference.md).
- [Apply detector efficiency and dead-time corrections](./pages/corrections.md).
- [Display neutron flux in both Time-of-Flight and Energy domains.](./pages/neutron_flux.md)
- [Perform Maxwellian and Maxwellian + Epithermal fits.](./pages/fitting.md)
- [Compute neutron cross sections.](./pages/cross_sections.md)
- [Export publication-quality figures.](./pages/exporting.md)

To understand how to use the Graphical User Interface, read [the workflow](./pages/workflow.md).

---

## Features

- Multiple dataset visualization
- Corrected ToF flux
- Energy spectrum conversion
- Least-square Maxwellian fitting
- Advanced nonlinear fitting
- Cross-section analysis
- Interactive plotting tools
- Figure history
- Data export
