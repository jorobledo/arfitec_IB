# Exporting Figures and Data

This page explains how to export figures and numerical data generated by the software.

---

# Export Menu

All export options are available from the `File` menu located in the menu bar.

Two export methods are available:

* `Save Plot`
* `Export Data`

---

# Save Plot

The `Save Plot` option exports an image of the currently displayed figure.

Procedure:

1. Generate the desired plot.
2. Open the `File` menu.
3. Click `Save Plot`.
4. Choose the destination folder.
5. Enter a file name.
6. Save the figure.

The exported image corresponds exactly to the plot currently displayed in the application, including:

* Selected datasets
* Axis limits
* Logarithmic scales
* Legends
* Fitted curves
* Reference data

Typical use:

* Reports
* Presentations
* Publications
* Experimental documentation

---

# Export Data

The `Export Data` option exports the numerical data associated with the currently displayed plot.

Procedure:

1. Generate the desired plot.
2. Open the `File` menu.
3. Click `Export Data`.
4. Select the curve(s) to export.
5. Choose the destination folder.
6. Save the exported file.

When several curves are displayed on the same figure, the software allows the user to select which curve(s) should be exported.

Typical examples:

* Experimental spectrum only.
* Fitted Maxwellian curve only.
* Experimental and theoretical curves.
* Cross-section references.
* Transmission curves.

---

# Exported File Format

The exported data are saved as plain text files.

The number of columns depends on whether uncertainties are available.

## Two-Column Format

Used when no uncertainty information is available.

| Column | Content  |
| ------ | -------- |
| 1      | X values |
| 2      | Y values |

Example:

```text id="1e8u8d"
x           y
0.001       12.5
0.002       14.8
0.003       15.2
```

---

## Three-Column Format

Used when uncertainties are available.

| Column | Content       |
| ------ | ------------- |
| 1      | X values      |
| 2      | Y values      |
| 3      | Uncertainties |

Example:

```text id="7p4hri"
x           y           uncertainty
0.001       12.5        0.4
0.002       14.8        0.5
0.003       15.2        0.4
```

---

# Typical Workflow

1. Generate the desired plot.
2. Verify that the correct datasets are displayed.
3. Open the `File` menu.
4. Use `Save Plot` to export an image of the figure.
5. Use `Export Data` to export the numerical values associated with one or more displayed curves.

The exported data can then be used in external software such as Excel, Origin, MATLAB, Python or other scientific analysis tools.
